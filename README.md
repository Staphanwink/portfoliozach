# Sachintha Senavirathna — portfolio

A responsive, static portfolio focused on custom Next.js/React development, technical SEO and the Tution.lk project, with science and leadership experience drawn from Sachintha's LinkedIn profile.

## Run locally

No installation or build is required. Serve this folder with any static HTTP server, or open `index.html` directly.

## Deploy on GitHub Pages

Publish this folder at the root of a public repository. In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

All asset paths are relative, so both `username.github.io` and project repository Pages URLs work. `.nojekyll` bypasses Jekyll processing.
